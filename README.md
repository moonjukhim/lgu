## 교육 전에 꼭 확인할 것 (리허설)

아직 실제 AWS 계정에서 실행해 보지 않았습니다. 템플릿은 cfn-lint를 통과했고, 셸 스크립트는 `bash -n`, 평가 도구는 오프라인 리포트로 확인했습니다. D-3 리허설에서 아래를 확인하세요.
0. 새 계정에서 `setup.sh` → ‘준비 완료’, `status.sh` 진도 표시, `cleanup.sh` 후 남은 리소스 0
1. 콘솔에서 Application Signals 계측 없이 ALB 지표로 SLO를 만들 수 있는지, 번레이트 경보 메뉴의 이름과 위치
2. 60 VU 부하로 CPU 50%를 넘겨 3~4대로 확장되는지, 콜드 응답(warm=false)이 보이는지
3. FIS 템플릿을 만들고 실행할 수 있는지, 대상 태그를 잘못 넣으면 역할이 종료를 거부하는지
4. 서울 리전 Bedrock에서 `converse`가 받는 대상 · Judge 모델 ID와 CloudShell에서 `jq` 명령이 동작하는지
5. 참가자 계정마다 vCPU 한도 8 이상 — 사전 과제 `setup.sh userNN --check` 회신으로 확인
6. CloudShell에서 한글 폴더명(`정답/`)이 들어 있는 zip이 정상으로 풀리는지
